プライバシーポリシー

最終更新日: 2026-09-12

TODO_PUBLISHER_NAME（以下「運営者」）は、Google スプレッドシート用アドオン「日本の住所正規化関数」（以下「本アドオン」）における情報の取り扱いについて、以下のとおり定めます。

1. 本アドオンが扱う情報

  • 本アドオンは、カスタム関数 NORMALIZE_JPN_ADDRESS の引数として渡されたセルの値、またはメニュー実行時に選択されていたセルの値（住所文字列）を、正規化のために実行中のメモリ上で処理します。メニュー実行時は、選択した列の右隣のセルに結果を書き込みます。それ以外のセルは読み書きしません。
  • 処理した住所文字列および正規化結果を、運営者が保存・収集・送信することはありません。運営者は本アドオンのためのサーバーを運用していません。
  • 本アドオンは、引数として渡されたセル以外のセル、スプレッドシートのファイル名や共有設定、利用者のメールアドレスや氏名を読み取りません。
  • メニューとサイドバーを使うとき、本アドオンは Google が発行する利用者のアカウント識別子（OpenID Connect の sub。数字だけの文字列）を読み取ります。ライセンスキーがそのアカウント用に発行されたものかを照合するためで、この照合はアドオン内で行い、識別子を運営者へ送信・保存することはありません。カスタム関数の実行では読み取りません。
  • ライセンスキーを登録すると、キーは Google Apps Script のユーザープロパティ（利用者のアカウントに紐づく保存領域）に保存されます。これは Google のサーバー上にあり、運営者には送信されません。サイドバーの「削除」でいつでも消せます。

1-2. 購入時の情報

ライセンスキーの購入は Stripe, Inc. の決済ページで行います。氏名、メールアドレス、カード情報は Stripe が取り扱い、Stripe のプライバシーポリシーに従います。サイドバーの購入リンクには上記のアカウント識別子が付き、Stripe の決済記録に保存されます。購入したアカウント専用のキーを発行するためで、運営者はこの識別子から氏名やメールアドレスを知ることはできません。運営者は Stripe の管理画面で購入者のメールアドレス、アカウント識別子、決済の記録を閲覧できます。これは領収書の再発行、返金、キーの再表示・再発行への対応にのみ使い、他の目的には使いません。キーの表示ページは本サイトと同じ Cloudflare Pages 上で動き、決済の確認のために Stripe の API に決済セッション ID を送ります。

2. 外部サービスへの通信

  • 本アドオンは、正規化に必要な住所データを、運営者が配信する住所データサーバー（normalize-jpn-address-data.pizzabunlab.com）から取得します。このデータは、Geolonia Inc. が公開する Geolonia 住所データ v2（デジタル庁「アドレス・ベース・レジストリ」を元に整備されたもの）から生成した静的ファイルです。
  • 取得するのは、都道府県・市区町村の一覧、市区町村ごとの町丁目一覧、町丁目ごとの番地・号の一覧といった公開データです。
  • この取得リクエストの URL には、入力された住所から判定した都道府県名・市区町村名、および町丁目に対応するデータの範囲が含まれます。入力された住所文字列そのもの、番地・号、建物名、スプレッドシートの内容は送信しません。
  • 通信は Google のサーバー（Google Apps Script）から行われます。配信サーバーには利用者の IP アドレスや Google アカウントの情報は届きません。
  • 配信サーバーは Cloudflare, Inc. のサービス（Cloudflare R2 および CDN）上で運用しています。運営者は配信サーバーのアクセス記録を保存せず、Cloudflare が通信の処理のために扱う情報は Cloudflare のプライバシーポリシーに従います。
  • 配信サーバーに障害がある場合、運営者は取得先を一時的に Geolonia Inc. が公開する配信サーバー（japanese-addresses-v2.geoloniamaps.com）へ切り替えることがあります。送信される内容は上記と同じで、その間のアクセス記録の取り扱いは Geolonia Inc. の定めに従います。

3. キャッシュ

取得した住所データは、通信量を減らすために Google Apps Script の CacheService に最大 6 時間保存されます。利用者が入力した住所や正規化結果は保存しません。

4. 要求する権限（OAuth スコープ）と用途

スコープ用途
openidメニューとサイドバーで、ライセンスキーが利用者の Google アカウント用に発行されたものかを照合するため。読み取るのはアカウント識別子（sub）だけで、メールアドレスやプロフィールは含まれません。
script.external_request住所データ配信サーバー（normalize-jpn-address-data.pizzabunlab.com、切り替え時は japanese-addresses-v2.geoloniamaps.com）から住所データを取得するため。接続先はこの 2 つに限定しています。
script.container.ui「拡張機能」メニューと使い方のサイドバーを表示するため。
spreadsheets.currentonly開いているスプレッドシートでカスタム関数とメニューを動作させるため。セルの読み書きは、関数の引数と戻り値の範囲に限られます。

5. Google API から取得した情報の取り扱い

本アドオンによる Google API から受け取った情報の使用および他のアプリへの転送は、Limited Use の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

6. アクセス解析・広告・Cookie

本アドオンは、アクセス解析ツール、広告、Cookie を使用しません。本ウェブサイトは GitHub Pages で提供しており、GitHub によるアクセス記録の取り扱いは GitHub のプライバシーに関する声明に従います。

7. 第三者への提供

運営者は利用者の情報を保有しないため、第三者に提供することはありません。

8. 本ポリシーの変更

本ポリシーは、法令の変更や本アドオンの仕様変更に応じて改定することがあります。改定後のポリシーは本ページに掲載した時点で効力を生じます。
