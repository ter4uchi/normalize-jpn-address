プライバシーポリシー

最終更新日: {{lastUpdated}}

{{publisher}}（以下「運営者」）は、Google スプレッドシート用アドオン「{{appName}}」（以下「本アドオン」）における情報の取り扱いについて、以下のとおり定めます。

1. 本アドオンが扱う情報

  • 本アドオンは、カスタム関数 {{functionName}} の引数として渡されたセルの値（住所文字列）を、正規化のために実行中のメモリ上で処理します。
  • 処理した住所文字列および正規化結果を、運営者が保存・収集・送信することはありません。運営者は本アドオンのためのサーバーを運用していません。
  • 本アドオンは、引数として渡されたセル以外のセル、スプレッドシートのファイル名や共有設定、利用者の Google アカウント情報（メールアドレス等）を読み取りません。

2. 外部サービスへの通信

  • 本アドオンは、正規化に必要な住所データを、Geolonia Inc. が公開する住所データ配信サーバー（{{apiHost}}）から取得します。
  • 取得するのは、都道府県・市区町村の一覧、市区町村ごとの町丁目一覧、町丁目ごとの番地・号の一覧といった公開データです。
  • この取得リクエストの URL には、入力された住所から判定した都道府県名・市区町村名、および町丁目に対応するデータの範囲が含まれます。入力された住所文字列そのもの、番地・号、建物名、スプレッドシートの内容は送信しません。
  • 通信は Google のサーバー（Google Apps Script）から行われます。配信サーバー側でのアクセス記録の取り扱いは、Geolonia Inc. の定めに従います。

3. キャッシュ

取得した住所データ（Geolonia が公開するデータ）は、通信量を減らすために Google Apps Script の CacheService に最大 6 時間保存されます。利用者が入力した住所や正規化結果は保存しません。

4. 要求する権限（OAuth スコープ）と用途

スコープ用途
script.external_request住所データ配信サーバーから住所データを取得するため。
script.container.ui「拡張機能」メニューと使い方のサイドバーを表示するため。
spreadsheets.currentonly開いているスプレッドシートでカスタム関数とメニューを動作させるため。セルの読み書きは、関数の引数と戻り値の範囲に限られます。

5. Google API から取得した情報の取り扱い

本アドオンによる Google API から受け取った情報の使用および他のアプリへの転送は、Limited Use の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

6. アクセス解析・広告・Cookie

本アドオンは、アクセス解析ツール、広告、Cookie を使用しません。本ウェブサイトは GitHub Pages で提供しており、GitHub によるアクセス記録の取り扱いは GitHub のプライバシーに関する声明に従います。

7. 第三者への提供

運営者は利用者の情報を保有しないため、第三者に提供することはありません。

8. 本ポリシーの変更

本ポリシーは、法令の変更や本アドオンの仕様変更に応じて改定することがあります。改定後のポリシーは本ページに掲載した時点で効力を生じます。

9. お問い合わせ

本ポリシーに関するお問い合わせは {{contactUrl}} までお願いします。
